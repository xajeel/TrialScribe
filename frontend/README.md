# frontend

Frontend applications for TrialScribe.

| App | Status |
|-----|--------|
| [streamlit-ui](streamlit-ui) | active (interim) |
| [web](web) | planned |

`streamlit-ui` is the current, interim UI. It will be replaced by the React SPA in `web` once
the backend's session, auth, and job-status APIs are stable enough to build a real frontend
against.
